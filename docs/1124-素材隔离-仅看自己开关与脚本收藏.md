# 批 T（11-24）素材隔离：「仅看自己」开关 ＋ 脚本库收藏

## 0. 需求原话（本批唯一口径）

> 「对了，加入素材隔离的概念，但默认是要能看到全部的，但是可以加入一个开关或者复选框，仅看自己。这个仅看自己，不是说仅仅是自己导入的文案也可以在已有的脚本库里面勾选，然后收藏起来。」

拆成三条硬约束，本批每一条都有对应判据：

1. **默认＝看全部**。隔离是 opt-in，不是新默认，也不按角色给不同默认值；
2. **一颗开关**（不是每个列表各配一个），选择跟着账号走（存后端，换浏览器还在）；
3. **「仅看自己」≠「只看到我导入的」**：还要能在脚本库里把**同事的**脚本勾起来收藏，收藏过的就算我的。

与 11-03 那条拍板「素材内容全量可见，取消 data_scope 隔离」不冲突：那条管的是**权限**（谁都能看、都能读到别人的内容），本批加的是**视图偏好**（愿意只看自己那一侧就自己关上）。写权限一个字没动。

## 2. 前端接法

一颗全局开关 → 五个列表，中间靠 `frontend/src/hooks/useOwnerView.ts` 这座桥：

- `AssetLibrary.tsx` 一次读回整个 `ui_config`（`asset_library_mode` ＋ `asset_scope_mine`），把 `scopeMine` 作为 prop 发给 `AssetListPanel`／`AssetReviewPanel`／`AssetProductionPanel`／`SimpleLibrary`，`AssetOutputWall` 收的是 `ownerDefault`；
- 四个面板原来各自的「我的/全部」`useState` 换成 `useOwnerView(scopeMine)`：**开关翻了，已经挂着的面板一起收**；面板里局部切那一下**不写回**全局开关（局部选择是一次性的，全局那颗才是存进后端的）；
- ⭐ 收藏列挂在 ① 脚本库表格上（`SimpleLibrary.tsx`；本档写成「②」是批 T 当天的编号，11-24 晚二轮把「导入」并进来后它是**①**，见 `docs/1124-极简二轮-导入并入我的口径与失败缺口.md`），点一下 `PUT …/favorite`、再点 `DELETE`，成功后重取列表；
- 「谁的」列的显隐判据从「跟着开关走」改成**跟着数据走**：`owner === 'all' || 当前页里混进了别人的行`。因为收藏之后，「我的」这一侧就会出现同事的稿子——这时候把「谁的」藏掉，用户看到的是一条来路不明的脚本。现在它写 **过审人的显示名** ＋ ` · 收藏`（库里 materialtest 的显示名是「素材员·测试」，界面上不会出现裸用户名）。
- 顶栏「待投」角标也改成跟这颗开关走（`AssetLibrary.tsx:347` 那颗 count 探针原来还留着 A′ 的角色分支 `role === 'operator' ? 'me' : 'all'`）。这是**网络层判据抓出来的第六条面板**：开着开关角标写 12、点进去生产单只有 3，正是最容易挨骂的「两个数对不上」。「等审核」那颗不用动——后端 `owner=me` 时 pending 区仍全量共享（6734 行），角标和列表本来就同源。

星标按钮的可访问态只能靠 `aria-label` 认：antd 的 `StarFilled` 和 `StarOutlined` 渲染出来的 class **都是** `anticon-star`，用 class 判「收没收藏」会永远判成同一个值（CDP 门里 T5e 就是钉这一条）。

## 3. 这条改动推掉了什么（要单独说，别当没发生）

`docs/素材库按运营隔离-设计方案-20261107.md`（A′ 那版）给的是**按角色默认**：运营/素材号进来看「我的」，管理员看「全部」。本批按用户这条原话改成**所有人默认看全部**，运营也一样——隔离变成用户自己那颗开关。

后果：一线同学第一次进来会看到全量内容（比 A′ 那版更"吵"）。这是这条需求的直接读法，不是漏配。若之后想给一线一个更安静的默认，得再拍一次板，别在代码里偷偷留角色分支。
