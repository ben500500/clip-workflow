# 三角色体系综合评审报告（多轮打分制）— 2026-11-08

## 业务模型（用户口径）
① **素材专员**：每天收集素材，链接/原片放进系统，反推成提示词并浓缩成文案；
② **审核专员**：将生成好的文案及提示词进行审核（质检关卡）；
③ **投放专员**：从审核好的素材库挑选所需文案及提示词，用豆包生产，产出 AI 素材去投放。

评审方式：六席专家（三角色本人视角＋流程架构＋界面交互＋权限运维）× 两轮打分制。
第一轮各自核码评分＋提改进提案（共 21 条）；第二轮合成统一方案后六席交叉打分定稿。
（CNB 的 NPC 评审为 PR 触发式代码评审，不适合产品级多轮打分，故以本地专家团执行，本报告可直接挂 CNB issue 引用。）

**六席共识的最重问题（Top 5）**：
1. 【架构】operator 一个角色兼审核+投放两个岗位——"自审自投一条龙"结构性合法（自审闸只比对素材导入人，不比对文案生成人）
2. 【架构】reviewed_by 双载"质检记录+归属锚点"——与"投放专员挑选时才归属"的三角色模型冲突；若审核/投放分人，跨人确认闸会从例外退化为例行仪式
3. 【投放】取号要出系统跑脚本（SSH）＋成片下载后到发布侧零衔接（板侧命名、标题不随片走、人肉搬运）
4. 【界面】三个角色打开系统都落"素材列表"第一屏"先找活"；生产单页筛选与动作混排破 #110 口径、批次筛选是手贴 UUID
5. 【审核】一致性签字够不着原文（无原片播放/脚本入口/实体清单）；重提说明只进审计、审核人看不见

## 第二轮：合成方案与交叉打分

六席 21 条提案合成统一方案（P0 立即做 6 项 / P1 排期 8 项 / P2 待拍板 4 项），六席交叉打分。

### P0 立即做（S 级，本周可上）
1. **归属锚点改语义不改表**：production.created_by 升主锚点（挑选即归属）、reviewed_by 降为质检记录（灰字"质检：X"）；跨人确认从"每次弹"改为例外（会话级/一次性或持投产职能默认放行＋strict 审计）
2. **operator 拆职能不拆账号**：can_review/can_produce 职能开关默认双开；自审自投可配硬闸（自审判定扩展到过审人）；需要岗位隔离的组只关开关
3. **生产单页排版对齐 #110**：筛选行与动作行分行；批次/素材筛选从手贴 UUID 换下拉
4. **页签角色化默认着陆＋待办计数**：material→导入与批次、审核相关→审核台（等审核 N）、投放→生产单（还没投 N）、后台任务（在跑 N）
5. **出文案轻量确认单**（同为花钱动作，口径补齐）
6. **术语四词收敛**：按钮"投板"、叙述"投产"、字段"投板稿"、产物"成片"；"读视频"→"反推文案"

### P1 排期（M 级）

## 最终结果（最高分数方案）

**P0＋P1 合并执行（均分 86-88），P2 停车场**。合并时吸收六席放行条件的最终口径：

### 执行批次一（P0，S 级，含第二轮修正）
1. 归属锚点改语义：投产人=主锚点、过审人=质检记录（灰字"质检：X"全站一步到位，页签/标签/弹窗/角色 Tag 同批换）；跨人确认改**会话级一次性**（不选无感放行），闸仍在 async 分支之前判，strict owner_cross 审计保留
2. operator 拆职能不拆账号：can_review/can_produce 开关默认双开；**自审硬闸默认开**（自己过审的候选自己投产默认拦，放开=admin 显式关＋逐条豁免留档）；职能判定收在 _REVIEW_ROLES 单点；开关改动走审计（user.position.update）
3. 生产单页排版对齐 #110＋批次/素材筛选换可搜索下拉（showSearch＋保留贴 ID 兜底）
4. 页签角色化默认着陆＋待办计数徽标（标口径：等审核=共享池）＋记住上次页签＋"最近审核活动"只读展示
5. 出文案确认单：**阈值触发**（≤4 条直发；≥5 条/覆盖重出/余额异常才弹），条数＋预计耗时（条数×95s），**不编金额**
6. 术语四词收敛＋"质检"全站改名同批；验收标准：质检/投产两词不得出现在同一按钮
7. 批次码一键跳转（从 P2 提入，S 级一行活）

### 执行批次二（P1，M 级）
8. 取号进界面（后端代理 hook_id.py＋保留手工粘贴旁路）
9. 成片交付包：跨组投放篮子（sessionStorage 持久）＋zip＋manifest（钩子号/推荐标题/剧缩/验收/归属，发布侧命名）；**export 附归属提入本批**
10. 审核卡一致性核验入口（看脚本/看原片/实体命中清单）
11. 重提说明与轮次上卡
12. 导入重复预检＋选档帮手（只用已落库时长，标 0 元）
13. 审计读口（仅 admin＋索引确认＋告警限频）＋fail-soft 告警＋补两处审计
14. 部署门禁与回滚（HEAD 已在远端校验＋last-good tag＋schema 兼容判定）
15. 挑选器历史单回显（防重复开单烧号池，S 级防呆提入）
16. data_scope 收口（隐藏编辑口＋标注仅项目域生效；export 对 material 收口）

### P2 停车场（拍板后再排）
17. production_note 交接单；18. 队列协作信号（**只提示不锁池**——动锁池即推翻候选池共享拍板）；19. 挑选器关键词搜索；20. 任务 ETA
