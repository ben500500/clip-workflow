## 1. 界面结构（改版后）

```
素材库 · 极简模式（Segmented「极简|完整」，偏好落 user_preferences.ui_config）
├── ① 导稿      导入钩子视频并反推 / 上传脚本文件 / 手写脚本 ＋ 新脚本原型
├── ② 脚本库    预览｜脚本｜原型｜状态｜已投｜(谁的)｜操作   ←「只有定稿的脚本能投豆包」
├── ③ 投豆包    这次要投的脚本（N）＋每个出几版＋人物三视图＋主按钮（按角色两种话术）
└── ④ 看成片    拼接指引 Alert ＋ 成片素材墙（AssetOutputWall，active 才拉数）
```

预览这一路的三个组件（`SimplePreviewBits.tsx`）：

- `useCoverMap(assetIds)` — 把当页所有 `origin_asset_id` 去重排序成一个 key，分批打 `GET /api/assets/frames`（**一次最多 50 个对象**，超了后端直接 400），取每条首帧 URL 当封面；
- `ThumbCell` — 9:16 小格；没帧时是虚线「无图」占位，浮窗说清「原片还没下载到桶里，或抽帧没跑成——不影响改稿与投产」，避免一线以为功能坏了；
- `VideoPreviewModal` — 全站**共用一个**播放器（列表几十上百行，每行挂一个 Modal 组件树白烧渲染），走 `GET /api/assets/{id}/source-preview`；`mode==='external'` 的站外链接直说「播不了」而不是给个黑框。

## 4. 门自己抓出的三个坑（都是我的验收脚本的坑，不是产品的）

1. **`shot()` 不 await 会抢下一跳的页面。** 八处截图全写成裸调用，结果 `p3-produce-chips.png` 实际截到的是 ④ 的内容，`p4-outputs-wall.png`／`c-material-role.png` 干脆没落盘（进程退出时 capture 还没回来）。现在一律 `await shot(...)`，并把 `shot` 包进 try/catch——截图失败打 WARN，不拖垮整道门。
2. **新增「预览」列让固定列号失效。** 原来按 `.ant-table-cell:nth-child(2)` 认脚本名，加列后第 2 格是缩略图，`P6/P7` 拿到空数组 → 连锁让 P9/P10 报 0 条。改成按整行 `innerText` 认行，不再依赖列序。
3. **全局 `querySelector` 会把隐藏面板判成"看得见"。** antd 访问过的面板留在 DOM 里只是 `display:none`，所以「③ 有这张卡」在 ④ 屏上也能查到——这是**假绿**。现在所有屏内判据都限定在**最外层活动面板**（脚本里的 `ACTIVE` 表达式）里查。

第 3 条最值钱：以后写页签类 UI 的门，判据必须锁活动面板，否则改版等于没验。
