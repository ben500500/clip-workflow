## 一、系统现在是什么

### 业务模型（三角色）

| 角色 | 干什么 | 系统实现 |
|---|---|---|
| **素材专员** | 每天收素材：链接/原片进系统 → 反推成提示词 → 浓缩成钩子文案 | `material` 角色 |
| **审核专员** | 质检关卡：过审 / 驳回 / 要求改写 / 改后过 | `operator` + 质检职能 |
| **投放专员** | 从过审库里挑文案 → 豆包生产 → 拿成片去投放 | `operator` + 投产职能 |
| 管理员 | 全能 + 用户管理（职能开关在此按人配置） | `admin` |

**拆职能不拆账号**：审核与投产是两个职能开关（`can_review` / `can_produce`），默认双开；要岗位隔离就在「用户管理 → 职能」里按人关掉对应项。

### 一条完整业务链（页签顺序即流程顺序）

```
① 导入 → ② 素材与文案（反推/出文案）→ ③ 文案审核 → ④ 生产与投板 → ⑤ 成片墙
                                                          （后台任务：公共台账，不占流程编号）
```
